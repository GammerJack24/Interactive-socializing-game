# Interactive Socializing Game

This game is a web based logic game, where players get a part of a image or text, and need to connect to find out the complete picture or message.

## How to Play
1. Open the game in your web browser.
2. Each player will receive a part of an image or a piece of text.
3. Players must communicate and collaborate to piece together the complete image or message.
4. The first player or team to correctly assemble the full picture or message wins.
